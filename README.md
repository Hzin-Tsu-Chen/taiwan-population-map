# 台灣空間決策分析平台

> 🔗 **線上 Demo（支援手機）**：https://hzin-tsu-chen.github.io/taiwan-population-map/

整合政府開放資料，以空間分析回答**兩個真實的決策問題**。平台化設計，可擴充更多分析模組。

| 模組 | 回答的問題 | 決策輸出 |
|---|---|---|
| 🍜 **餐飲業選址分析** | 開一家餐飲店，哪一區的市場最未飽和？ | 藍海／紅海鄉鎮排名 |
| 🏥 **長照資源缺口分析** | 哪些地區長照資源最不足，該優先增設？ | 各鄉鎮達標尚缺床位數 |

---

## 【使用技術】

- **Python / pandas** — 多來源資料整合、ETL
- **geopandas** — 空間資料處理、座標系轉換、幾何簡化
- **folium / Leaflet** — 互動式地圖（Choropleth 分級著色）
- **政府開放資料 API** — 內政部戶政司、衛福部食藥署、衛福部社家署
- **HTML / CSS / JavaScript** — RWD 響應式儀表板、跨框架事件通訊（postMessage）

## 【核心功能】

### 模組一：餐飲業選址分析

```
機會指數 = 競爭分數 (60%) + 成長分數 (40%)

競爭分數：每店服務人口的百分位（越高 = 店少人多 = 市場未飽和）
成長分數：人口淨變化率的百分位
評估門檻：人口 ≥ 20,000 的鄉鎮
```

**全國基準**：平均每家餐飲店服務 102 人

### 模組二：長照資源缺口分析

```
供給密度 = 核定床位數 / 65歲以上人口 × 1000   （每千名老人床位數）
缺口指數 = (1 − 供給密度 / 全國平均) × 100     （0=達標，100=完全空白）
達標缺床 = 老年人口 × 全國平均 / 1000 − 現有床位
```

**全國基準**：每千名老人 **13.7 床**

## 【成果說明】

### 主要發現

**餐飲選址**：臺中市外埔區每店服務 376 人（全國平均 3.7 倍），市場明顯未飽和。

**長照缺口（反直覺的發現）**：最缺床位的並非偏鄉，而是**臺北市蛋黃區**——大安區有 72,468 位長者卻僅 242 床，達全國平均尚缺 753 床。原因推測為土地成本高、機構設置不易。此發現顯示「都會區長照資源相對稀缺」的政策議題。

### 資料工程重點

- **地址解析除錯**：初版以正規表達式解析地址，發現「前鎮區」被誤截為「前鎮」、「新市區」誤截為「新市」（因鄉鎮名本身含「鎮/市」字元），導致部分行政區店數為 0。改以「已知鄉鎮名清單、最長名稱優先」比對，成功率達 **99.96%**。
- **資料集辨識錯誤修正**：初次選用戶政司 ODRP072 抓取年齡結構，加總後全台僅 332 位長者，遠低於合理值。追查後發現該資料集為「**歸化定居人口**」（大陸／港澳／東南亞核准定居者）之子群，非一般人口。改用 ODRP052（現住人口按性別、年齡、婚姻狀況）後得 **4,488,707 人**，通過合理性檢查。
- **編碼處理**：社家署資料為 **Big5** 編碼（政府舊系統常見），需正確解碼避免亂碼。
- **反爬蟲處理**：data.gov.tw 對無 User-Agent 的請求回 403，需帶瀏覽器標頭。
- **合理性檢查**：以全台總人口 2,328 萬、老年人口約 450 萬、彰化縣長照床位 3,681 床等指標交叉驗證加總正確性。

### 模型限制（誠實揭露）

**餐飲選址**：以「居住人口」為市場基礎，商業區（如臺中中區）有大量通勤消費人口，商機被低估；郊區可能因外食習慣較低而被高估。

**長照分析**：資料為「**老人福利機構**」名冊（住宿式安養／養護），**不含**護理之家（依《護理機構法》另管）與長照 2.0 的居家式／社區式服務。因此「0 床」代表無住宿式老人福利機構，**不等於毫無長照資源**。此外年齡結構資料最新僅至 2024 年。

## 如何執行

```bash
pip install geopandas folium pandas

python3 fetch_town_data.py    # 人口 + 餐飲場所 → town_indicators.csv
python3 fetch_elderly.py      # 65歲以上人口   → elderly_by_town.csv
python3 fetch_ltc.py          # 長照機構 + 供需 → ltc_indicators.csv
python3 build_dashboard.py    # 產生雙模組儀表板 → index.html
```

## 檔案說明

| 檔案 | 說明 |
|---|---|
| `fetch_town_data.py` | ETL：人口 + 餐飲場所，地址解析 |
| `fetch_elderly.py` | ETL：65 歲以上老年人口（206 萬筆篩選加總）|
| `fetch_ltc.py` | ETL：長照機構（Big5）+ 供需指標計算 |
| `build_dashboard.py` | 分析模型 + 雙地圖 + RWD 儀表板產生 |
| `*_indicators.csv` | 整合後的鄉鎮級指標 |
| `index.html` | 雙模組互動儀表板 |
